# 高評価・レビュー数の範囲指定

2026-11-03 更新。従来の近さ優先を、この2種類の検索条件だけ変更します。

- 下限なし：取得候補のうち実測が上限以内の場所から、星／レビュー数を優先して最大8件を採用。
- 下限あり：実測が下限〜上限の場所のみ採用。不足時も下限未満で補充しない。
- 評価欠落・レビュー0件は対象外。星優先では同点をレビュー数で、レビュー数優先では同数を星で比較。さらに同点なら上限への近さ。
- その他の種類では近さ優先・下限未満の補充を維持。
- 表示の初期順序は従来通り条件に近い順。手動並び替え・追加検索のマージ方式は変更しない。
- 方向ごとの探索と未探索方向の経路枠は維持。最大5回の候補取得・24回の経路計算を維持するため、範囲内全施設での評価上位を保証するものではない。
