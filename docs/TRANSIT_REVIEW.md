# 電車機能の再検討

調査日: 2026-11-01。申込み・契約・課金サービスへの接続は行っていません。電車検索は引き続き停止。

## 実装前に解決する点

- 任意の出発地から駅、降車駅から目的地への徒歩を含める。駅間の時間だけで「120分以内」と表示しない。
- 平均所要時間と出発時刻に応じたダイヤ検索を区別。NAVITIMEの電車時刻表対応は直接契約の追加オプションとして掲載されているため、無料版で実ダイヤ検索できる前提にしない。
- 往復は両方向を検索し、待ち時間と滞在ゼロの帰路時刻を定義する。
- Google Placesで得たスポットと別会社の経路を組み合わせる際の両社の表示・帰属・保存・地図利用条件を確認する。
- 8候補を往復で調べる場合、単純実装では最大16経路呼出し。無料500アクセスなら約31回相当（追加の駅検索等を含めると減る）。これは構成上の試算で、プランの課金単位の確定値ではない。
- 買い切り単価は公示価格から1リクエスト1.1円相当。8候補往復16リクエストなら17.6円相当／検索（駅検索・徒歩・Google候補検索は別）。購入条件・消費単位は未確定。

## 提案

現段階では電車の実検索を復活させず、一般公開に向けた共有カウンターによる利用上限・自動停止を先行。必要なら目的地決定後にGoogle Mapsの公共交通リンクを加える方法を検討する。このリンクではアプリ内の電車所要時間による候補選定はできない。
