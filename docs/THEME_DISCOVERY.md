# 目的地の種類を候補収集へ反映（2026-11-03）

最新の評価条件・下限指定の優先順位は [RATING_RANGE_SELECTION.md](RATING_RANGE_SELECTION.md) を参照。

## 問題

以前は「すべて」「高評価」「レビュー数」で同じ広い施設分類をまとめてDISTANCE検索し、公園や小さな寺社が各検索の20件を埋めやすかった。「観光」も副分類にtourist_attractionが付いた公園を通していた。候補取得後の評価比較だけでは、取得できなかった博物館・景勝地・レジャー施設は選べない。

## 新しい収集計画

Nearby最大5回・Routes最大24回を維持する。GoogleのPOPULARITYへ戻さず、出発地からの四方向の時間補正も維持する。

1. 主分類 `includedPrimaryTypes` で候補を取得する。観光タグが付いていても主分類が普通のparkなら観光へ流用しない。自然条件へ博物館や遊園地も混ぜない。展望台は自然／景色にも含める。
2. 最初の四探索では、密集しやすいpark・garden・historical_landmark・shinto_shrine・buddhist_templeを別枠へ分ける。自然は海・山・自然保護区・ハイキング・植物園・展望台など、観光は観光名所・レジャー施設・博物館・文化施設を先に収集する。
3. 自然／観光を指定したときは、四方向すべてを指定分類で検索する。ほかの分類へ勝手に切り替えない。
4. すべて／高評価／レビュー数では、対向する二方向を自然、残る対向二方向を観光へ割り当て、それぞれの取得枠を確保する。追加ページでは方向の回転と併せて自然／観光の割り当ても交替する。この5回上限内の構成は、各分類を全四方向へ個別検索するものではない。
5. 最後の第五探索は指定分類全体へ広げ、公園・小庭園・史跡・寺社も補充する。公園・庭園・史跡・寺社を完全に除外する仕様ではない。初回の広い取得枠をすべて埋めさせないために収集段階を分ける。

検索範囲とカテゴリの条件は組み合わせて適用する。大きな公園の主分類が単にparkの場合は第五探索で対象になる。大きな寺社でも主分類がshinto_shrine／buddhist_templeなら補充枠からの取得であり、有名さによる特別扱いはしていない。史跡の主分類を持つ大きな城跡も第五探索の対象となる。Googleの分類の不足・誤りや返却件数による取りこぼしは残る。湖・河川・島など地理的な領域そのものの中心へ案内する分類は新設せず、景勝地・展望台・公園など訪問地点の分類から扱う。

## 候補の確認・採用

取得した主分類をPlaceへ保持し、海山景色・庭園・公園・レジャー・文化施設・史跡・寺社・観光名所へ整理する。名称や住所から推測した架空の分類は作らない。博物館の派生主分類（science_museumなど）はmuseumとして扱う。

上限への近さの帯（3%幅）を最優先し、同程度の候補で方位・施設分類・近接地点の偏りを抑える。そこから高評価／レビュー数の指標を比較する。大幅に短い博物館を、時間の合う公園より優先するような変更ではない。実測による上限判定、往復合算、下限未満補充、既出・除外済みの省略、追加結果の末尾マージは維持する。

高評価／レビュー数は前回の修正どおり評価あり・口コミ1件以上だけを対象とし、星4以上などの新しい閾値は設けていない。手動ソートも取得済み候補の順序変更のまま。

## 検証可能性

管理者の探索履歴へ分類別の候補数→採用数を追加した。候補不足なのか、公園しか収集できていないのか、取得済みでも上限への近さで別分類が不採用なのかを区別して確認する。サーバーログも分類名と集計値だけで、施設ID・施設名・座標・アカウントは保存しない。

## 検証

全2,557件合格、型検査・本番ビルド成功。新しい8ケースでは、公園80件・寺社60件が近接し、その外側に海山・庭園・博物館・遊園地・史跡が存在する合成応答を使い、各検索の主分類フィルタに従って最大20件を返す。広い共通検索では公園で埋まる構成でも、分類ごとの取得枠が確保され、自然・観光の区別と「すべて」での両方の採用が機能することを検証する。

以前のGoogle応答モックの一部は、どの施設分類を要求しても無条件にparkや分類なしを返していた。主分類フィルタを尊重する応答へ修正し、時間・距離への近さ・件数・API上限など従来の検証条件は維持した。

## 本番での五種類の比較

管理者枠で東京駅・車・高速利用可・往復120分・下限空欄を共通条件として確認した。一般利用者の回数は使っていない。すべての検索で方向確認4回を含む経路24回以内、候補探索5回以内だった。

|検索条件|件数|表示時間|採用分類の内訳|
|---|---:|---|---|
|自然・景色|8|106〜120分|自然保護区・展望台など4、公園4|
|観光・レジャー|7|107〜117分|観光名所2、文化施設1、史跡2、寺社2|
|すべて|8|106〜120分|自然保護区・展望台など4、公園2、寺社1、観光名所1|
|高評価|8|108〜120分|自然保護区・展望台など3、公園3、寺社1、レジャー1|
|レビュー数|8|102〜120分|自然保護区など4、公園3、寺社1|

自然と観光の共通候補は0件。高評価・レビュー数はいずれも全件が評価あり・口コミ1件以上だった。すべてと評価条件は同じ自然／観光の収集枠を使うので、候補の重複は残る。条件間で必ず全候補を別々にする操作や、表示件数のための範囲外・種類外の穴埋めはしていない。

管理者履歴では、すべての場合にも文化施設・レジャーの候補を収集している一方、今回の実測と予算の中では最終採用に至らなかったことを確認できた。取得枠の確保はその種類を必ず8件の中に採用する保証ではなく、時間・距離の近さの優先順位は維持する。上記は当該条件の確認であり、全地域で件数や分類比率を保証しない。
