# 公開運用

このディレクトリーがSitesへの公開元です。SitesのGitソースへコミットを同期し、同じコミットから作ったWorkerアーカイブをバージョン保存してデプロイします。

## 閲覧範囲

所有者本人のみ。同じアカウントでログインすればPC・スマートフォンから利用できます。Googleキーは現在未設定なのでデモ版です。

## GitHub

元のNext.jsアプリは隣の`kyou-doko`でGit管理済みです。GitHubへのpushにはGitHubの接続または認証済みのremoteが必要です。Sites内部ソースへの同期は、GitHubへの公開を意味しません。

## 今後の更新

両ディレクトリーを独立管理しているため、UI・ロジック変更時は対象ファイルを同期して両環境で検証します。将来は共有パッケージか単一リポジトリーへ統合するのが推奨です。

実APIを有効にする際は、Google Consoleで公開URLのリファラー制限を設定し、Places/Routes用の秘密キーとMaps表示専用の公開キーを分離。Sitesの環境変数へ登録し、環境設定を反映して再デプロイしてください。キーはサーバー側でリクエスト時に読み取ります。課金制限・利用量監視・実地域での少量疎通も先に確認します。
