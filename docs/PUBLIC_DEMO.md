# 一般公開デモと本人限定の実検索

一般公開では固定デモだけを提供し、Places/Routes API・Maps JavaScript APIを呼びません。一般閲覧者へ地図用キーも送信しません。Google Fontsは地図APIと別の無料フォント配信です。

実検索はSitesの認証ゲートウェイが付与・上書きするユーザーIDで本人を照合します。初期設定だけ、まだ本人限定の公開範囲で、Sitesの所有者情報から得たメールと認証IDの存在を確認します。その後、本人セッションのサイト固有IDをLIVE_SEARCH_OWNER_USER_IDへ固定します。メールやIDをリクエスト本文・URLパラメーターから受け付けません。

APIでGoogleプロバイダーを生成する前に認証・本人・停止スイッチを確認。未ログイン401、本人以外403。公開デモは認証不要で実行可能です。サービス用アクセス許可トークンはユーザー本人の認証の代わりになりません。

HTML・権限API・検索APIはprivate, no-store。ユーザーをまたいだ地図キーや権限のキャッシュを防止します。所有者以外の画面では通常検索・GPSを無効にし、設定ページも管理者限定にします。

## 環境変数

- LIVE_SEARCH_ENABLED=true のときだけ実検索を許可。falseへ変更し再デプロイすれば全員の実検索を停止。
- LIVE_SEARCH_OWNER_USER_ID: Sitesで認証された本人のサイト固有ID。秘密設定に保存。
- LIVE_SEARCH_OWNER_EMAIL: 本人限定公開中の初期ID確認用。ID固定後は不要。
- GOOGLE_MAPS_API_KEY / NEXT_PUBLIC_GOOGLE_MAPS_API_KEY: 引き続き秘密設定に保存。実際にブラウザーへ渡すのは本人に対する地図用キーのみ。

素のNext.jsサーバーをインターネットへ公開して認証ヘッダーをそのまま信用してはいけません。Next.js版はlocalhost用です。別ホストへ移す場合は信頼できる認証ゲートウェイを構築し、外部からの認証ヘッダーを削除・上書きしてください。

本人が実検索・Google地図を利用すれば従来どおりAPI利用量が発生します。一般閲覧者のアプリ操作にGoogle API利用量が発生しない構成であり、過去の利用分やキーのアプリ外不正利用まで請求ゼロを保証するものではありません。検索上限（10秒間隔・1時間30回）は本人にも維持します。

## 確認

匿名・別アカウント・停止状態ではGoogle fetchが一度も呼ばれないことを単体テスト。公開変更前後には匿名HTTP・ヘッダー偽装・サービス用アクセスの権限応答、デモ検索、HTMLのキー非露出を確認します。実Google検索の追加試験は費用抑制のため行いません。
